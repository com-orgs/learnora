Percentage Increase and Decrease

Prices change, populations grow, and discounts reduce costs. Learn how to calculate a percentage increase or decrease, find the amount of change, and work out a new value step by step.

Learning time: approximately 25–30 minutes · Beginner to intermediate

What You Will Learn

  • Find a percentage increase or decrease.
  • Calculate the amount of change.
  • Work out a new value after a percentage change.
  • Solve discount, price-rise and everyday problems.
  • Explain the difference between a percentage change and a percentage-point change.

1. What Is Percentage Change?

A percentage change compares how much a value has changed with its original value. The original value is the starting amount. Always use the original value as the base when calculating the percentage change.

Percentage change = (change ÷ original value) × 100%

First find the difference between the new value and the original value.

If the new value is greater, it is an increase. If the new value is smaller, it is a decrease.

2. Percentage Increase

A percentage increase happens when a value becomes larger.

Increase = original value × rate
New value = original value + increase

Write the percentage as a decimal before multiplying.

Worked example: A price rises by 10%

A school bag originally costs $40. Its price increases by 10%. Find the increase and the new price.

  1. Convert 10% to a decimal: 0.10.
  2. Find the increase: 40 × 0.10 = $4.
  3. Add the increase to the original price: 40 + 4 = $44.

Increase: $4. New price: $44.

Quick multiplier method: A 10% increase means 100% + 10% = 110%. Multiply the original value by 1.10. So $40 × 1.10 = $44.

3. Percentage Decrease

A percentage decrease happens when a value becomes smaller. Discounts and reductions are common examples.

Decrease = original value × rate
New value = original value − decrease

Worked example: A discount of 20%

A jacket costs $80. The shop offers a 20% discount. Find the discount and sale price.

  1. Convert 20% to 0.20.
  2. Find the discount: 80 × 0.20 = $16.
  3. Subtract the discount: 80 − 16 = $64.

Discount: $16. Sale price: $64.

Quick multiplier method: A 20% decrease leaves 80% of the original amount. Multiply by 0.80: $80 × 0.80 = $64.

4. Find the Percentage Change

Sometimes you know the old and new values but need to calculate the percentage change.

Worked example: A plant grows

A plant was 30 cm tall. It later measures 36 cm. What is the percentage increase?

  1. Find the change: 36 − 30 = 6 cm.
  2. Divide by the original value: 6 ÷ 30 = 0.2.
  3. Convert to a percentage: 0.2 × 100% = 20%.

The plant's height increased by 20%.

Worked example: A price falls

A game originally costs $50 and is now $40. Change = 50 − 40 = $10. Percentage decrease = 10 ÷ 50 × 100% = 20%.

6. Real-Life Problems

Example 1: A monthly bill increases

A monthly bill of $60 increases by 5%. Increase = 60 × 0.05 = $3. New bill = $63.

Example 2: A sale discount

A bicycle costs $240 and is reduced by 15%. Discount = 240 × 0.15 = $36. Sale price = 240 − 36 = $204.

Example 3: Attendance increases

A club had 80 members and now has 100. Increase = 20. Percentage increase = 20 ÷ 80 × 100% = 25%.

7. Common Mistakes

Using the new value as the base: Percentage change is calculated using the original value in the denominator.
Adding the percentage number directly: A 20% increase on $50 is $10, not $20. Calculate 20% of the original amount first.
Subtracting the wrong amount: For a decrease, subtract the calculated decrease from the original value.
Mixing up increase and decrease multipliers: A 15% increase uses 1.15; a 15% decrease uses 0.85.
Confusing percentage points with percent change: A rate moving from 20% to 25% rises by 5 percentage points. Relative to 20%, that is a 25% increase.

8. Practice Exercises

  1. A $50 item increases in price by 10%. Find the increase and new price.
  2. A $120 pair of shoes is discounted by 25%. Find the discount and sale price.
  3. A value rises from 40 to 50. Find the percentage increase.
  4. A quantity falls from 200 to 170. Find the percentage decrease.
  5. Write the multiplier for a 12% increase.
  6. Write the multiplier for a 35% decrease.
Show practice answers and working
  1. Increase = 50 × 0.10 = $5; new price = $55.
  2. Discount = 120 × 0.25 = $30; sale price = $90.
  3. Change = 10; 10 ÷ 40 × 100% = 25% increase.
  4. Change = 30; 30 ÷ 200 × 100% = 15% decrease.
  5. 1 + 0.12 = 1.12.
  6. 1 − 0.35 = 0.65.

11. Lesson Summary

  • Percentage change compares the change with the original value.
  • Percentage change = (change ÷ original value) × 100%.
  • For an increase, add the calculated change to the original value.
  • For a decrease, subtract the calculated change from the original value.
  • Multipliers make new-value calculations quicker: 1 + rate for an increase and 1 − rate for a decrease.
