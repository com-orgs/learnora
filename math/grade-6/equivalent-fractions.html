Equivalent Fractions

Discover how fractions with different numbers can represent exactly the same amount. Use visual models, learn the multiplication rule and practise simplifying fractions.

Learning time: approximately 20–25 minutes · Beginner level

What You Will Learn

  • Explain what equivalent fractions are.
  • Recognise equivalent fractions using visual models.
  • Find equivalent fractions by multiplying or dividing.
  • Simplify a fraction to its simplest form.
  • Check whether two fractions are equivalent.

1. What Are Equivalent Fractions?

Equivalent fractions are fractions that have different numerators or denominators but represent the same value.

For example, 1/2, 2/4 and 3/6 all represent one half.

2. Make Equivalent Fractions by Multiplying

To make an equivalent fraction, multiply the numerator and denominator by the same non-zero number.

Example: Start with 2/3

  1. Multiply the numerator and denominator by 2.
  2. Numerator: 2 × 2 = 4.
  3. Denominator: 3 × 2 = 6.
  4. So 2/3 = 4/6.
Remember: Whatever you do to the numerator, do the same to the denominator. Multiplying only one of them changes the value.

More examples:

  • 1/4 × 2/2 = 2/8
  • 3/5 × 3/3 = 9/15
  • 2/7 × 4/4 = 8/28

3. Simplify Fractions by Dividing

Simplifying means writing a fraction with smaller numbers while keeping the same value. Divide the numerator and denominator by the same common factor.

Example: Simplify 12/18

  1. Find a common factor of 12 and 18. Their greatest common factor is 6.
  2. Divide the numerator: 12 ÷ 6 = 2.
  3. Divide the denominator: 18 ÷ 6 = 3.
  4. The simplest form is 2/3.
Check: 2/3 × 6/6 = 12/18. The fractions are equivalent.

4. How to Check if Fractions Are Equivalent

You can simplify both fractions and see whether they become the same fraction.

Example: Are 3/4 and 6/8 equivalent?

  1. Start with 3/4.
  2. Multiply the numerator and denominator by 2: 3/4 = 6/8.
  3. The result matches the second fraction.

Answer: Yes, 3/4 and 6/8 are equivalent.

Another example: Are 2/3 and 3/5 equivalent?

2/3 cannot be changed into 3/5 by multiplying or dividing both terms by the same factor. Their values are different, so they are not equivalent.

5. Common Mistakes to Avoid

Changing only the numerator: Multiplying the top number but not the bottom number changes the fraction's value.
Changing only the denominator: Both parts must be multiplied or divided by the same non-zero number.
Stopping before simplest form: A fraction is fully simplified when the numerator and denominator have no common factor greater than 1.
Assuming bigger numbers mean a bigger fraction: 2/4 and 1/2 have different numbers but the same value.

6. Step-by-Step Practice Examples

Example 1: Find a fraction equivalent to 3/8 with denominator 24

8 × 3 = 24, so multiply the numerator by 3 as well: 3 × 3 = 9. Answer: 9/24.

Example 2: Simplify 15/20

The greatest common factor is 5. Divide both numbers by 5: 15 ÷ 5 = 3 and 20 ÷ 5 = 4. Answer: 3/4.

Example 3: Fill the missing number

4/5 = ?/20. Since 5 × 4 = 20, multiply the numerator by 4 too: 4 × 4 = 16. Answer: 16/20.

10. Lesson Summary

  • Equivalent fractions represent the same value.
  • Multiply both numerator and denominator by the same non-zero number to make an equivalent fraction.
  • Divide both by the same common factor to simplify.
  • Always perform the same operation on the numerator and denominator.
