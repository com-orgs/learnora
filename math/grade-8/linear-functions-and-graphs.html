Linear Functions and Graphs

A linear function describes a relationship with a constant rate of change. Its graph is a straight line.

Learning time: 20–25 minutes · Level: Developing

Learning goals

  • Evaluate a linear function for a given input and organise input-output values in a table.
  • Calculate slope from two points using change in y divided by change in x.
  • Identify slope and y-intercept in the form y = mx + b.
  • Graph a linear rule using its y-intercept and slope, then verify plotted points by substitution.
  • Interpret slope and y-intercept in simple real-world situations, including units.

1. Input and output

A function assigns exactly one output to each input. In y = 2x + 3, choose an x-value, substitute it, and calculate y. For x = 4, y = 11.

2. Tables and rules

Make an input-output table by substituting several x-values into the same rule. Ordered pairs (x, y) can then be plotted on a coordinate plane.

3. Slope or rate of change

Slope measures vertical change divided by horizontal change: m = (y₂ − y₁)/(x₂ − x₁). A positive slope rises left to right; a negative slope falls.

4. The y-intercept

In y = mx + b, m is the slope and b is the y-intercept, where the line crosses the y-axis. For y = 3x − 2, the slope is 3 and the y-intercept is −2.

5. Graph a linear rule

Plot the y-intercept first. Use the slope as rise/run to find another point, then draw a straight line through the points. Check by substituting a plotted point into the rule.

Interpret slope and intercept in context

A linear function has a constant rate of change. In y = mx + b, m is the slope and b is the y-intercept. The slope tells how much y changes when x increases by 1; the intercept is the output when x = 0. A positive slope rises from left to right, while a negative slope falls.

Worked reasoning: A line passes through (1, 5) and (3, 11). Its slope is (11 − 5) ÷ (3 − 1) = 6 ÷ 2 = 3. Substitute (1, 5) into y = 3x + b: 5 = 3 + b, so b = 2. The rule is y = 3x + 2.

If the situation describes a taxi fare with a fixed starting fee plus a charge for each kilometre, the intercept represents the starting fee and the slope represents the cost per kilometre.

  • Use the same order of points in the numerator and denominator when finding slope.
  • Do not confuse the y-intercept with the x-intercept.
  • Check a graph by substituting one plotted point into its equation.

Worked examples

  1. For y = 2x + 1, x = 0, 1, 2 gives y = 1, 3, 5.
  2. Between (1, 4) and (3, 10), slope = (10 − 4)/(3 − 1) = 3.
  3. In y = −2x + 5, slope = −2 and y-intercept = 5.

Independent practice

Attempt each problem before checking the worked answer.

  1. Find y when y = 3x + 2 and x = 4. Answer: 14.
  2. For y = −x + 6, find y when x = 2. Answer: 4.
  3. Find the slope between (2, 3) and (4, 9). Answer: 3.
  4. State the slope and y-intercept of y = 5x − 7. Answer: 5 and −7.
  5. Does y = 4x + 1 rise or fall left to right? Answer: Rise; slope is positive.
  6. Complete y = 2x for x = −1, 0, 3. Answer: −2, 0, 6.
  7. Find the y-intercept of y = −3x + 8. Answer: 8.
  8. A taxi costs $4 plus $2 per kilometre. Write the rule. Answer: C = 2k + 4.

Lesson Summary

  • A linear function has a constant rate of change and produces a straight-line graph.
  • The slope describes the change in output for each one-unit change in input.
  • The y-intercept is the output when the input is zero.
  • Use a table of values to calculate points and plot the line accurately.
  • Interpret slope and intercept in the context of the problem, including units.
