Linear Equations and Inequalities

An equation says two expressions are equal. An inequality compares values using signs such as <, >, ≤ and ≥.

Learning time: 20–25 minutes · Level: Developing

Learning goals

  • Explain the key ideas and use the correct mathematical language.
  • Follow worked examples and choose an appropriate method.
  • Apply the skill to practice problems and check your work.

1. Keep equations balanced

An equation stays equivalent when you perform the same operation on both sides. Use inverse operations to isolate the variable.

2. Multi-step equations

Simplify each side first, use the distributive property when needed, collect variable terms on one side, then isolate the variable. Always substitute your answer to check.

3. Variables on both sides

For 5x + 2 = 2x + 14, subtract 2x from both sides, then subtract 2: 3x = 12, so x = 4. If the variable terms cancel, the result may be always true (infinitely many solutions) or false (no solution).

4. Inequalities

Solve an inequality like an equation, but reverse the inequality sign when multiplying or dividing both sides by a negative number. For example, −2x < 8 becomes x > −4.

5. Show solutions

Use an open circle for < or > and a filled circle for ≤ or ≥ on a number line. Shade in the direction of values that satisfy the inequality. Test a value from the shaded region.

Worked examples

  1. 3(x + 2) = 21 → 3x + 6 = 21 → x = 5.
  2. 4x − 7 = 2x + 9 → 2x = 16 → x = 8.
  3. −3x ≥ 12 → x ≤ −4 (reverse the sign).
  4. 2(x − 1) + 5 = 11 → 2x + 3 = 11 → x = 4.

Independent practice

Try each question before revealing or checking the worked answer.

  1. Solve 5x − 4 = 21. Answer: x = 5.
  2. Solve 3(x + 2) = 24. Answer: x = 6.
  3. Solve 7x + 1 = 4x + 16. Answer: x = 5.
  4. Solve 2x − 5 < 9. Answer: x < 7.
  5. Solve −4x ≤ 20. Answer: x ≥ −5.
  6. Solve 6 − 2x > 12. Answer: x < −3.
  7. Solve 4(x − 1) = 2x + 10. Answer: x = 7.
  8. A number doubled and increased by 9 is 25. Answer: 2x + 9 = 25, x = 8.

Knowledge check

Choose one answer for each question, then check your answers. Explanations appear after checking.

1. Solve 4x + 3 = 19.

2. Solve 2(x + 5) = 18.

3. Solve −3x > 12.

4. Solve 5x − 2 = 3x + 8.

5. Which sign change is needed when dividing by a negative?
