Student tools help with schoolwork. Daily-life tools help with everyday numbers. Pick one below, or find the tool linked under the lesson you are reading.

How the tools link to lessons

Each lesson on Learnora links to the tool that practises its idea. For example, the fractions lessons link to the Fraction Visualiser, the percentages lessons link to the Percentage Calculator, and the equations lessons link to the Equation Solver. Learn the idea first, then use the tool to practise it.
