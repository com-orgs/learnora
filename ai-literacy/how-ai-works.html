How Artificial Intelligence Works

Artificial intelligence is a broad field in which computer systems perform tasks such as recognising patterns, processing language or making predictions. Many modern systems learn statistical patterns from examples and use them to produce outputs.

Learning time: 15–20 minutes · Beginner level · Free study resource

What you will learn

  • Describe AI as computer techniques, not a human mind.
  • Explain the role of data in machine learning.
  • Distinguish inputs, models and outputs.
  • Explain why AI results need human review.

1. Data and patterns

Artificial intelligence (AI) is a broad field of methods that help computers perform tasks such as recognising images, translating language or generating text. Machine learning (ML) is one approach within AI: software is trained using data so that a model can make predictions or generate outputs. Not every AI system works in the same way, and not every AI system learns from examples.

A dataset is a collection of examples. Each example may contain information called features. In supervised learning, some examples also have a known answer called a label.

Example: sorting messages

A training dataset might contain example messages labelled “spam” or “not spam”. Features could include words, links or other message patterns. The model learns relationships in those examples. The labels are supplied by people or another trusted process; the model does not magically know which messages are harmful.

The examples matter. If a dataset is too small, outdated or missing important kinds of messages, a model may work poorly on messages it has never seen. A model can also learn misleading patterns that happen to appear in its training examples.

2. Training and using a model

During training, a learning method uses examples and an objective to adjust a model so that its outputs fit the training task better. After training, the model can receive a new input and produce an output. Using a trained model on new input is often called inference.

  1. Collect examples: gather relevant data and check that it is suitable for the task.
  2. Prepare the data: organise examples and, for supervised learning, provide suitable labels.
  3. Train: use a learning method to adjust the model from the examples.
  4. Test: check the trained model on separate examples it did not train on.
  5. Review: look for errors and decide whether the model is suitable for its intended use.
Why keep test examples separate?

Imagine practising with one set of spelling questions and then checking your understanding with different questions. If you only repeat the exact practice questions, you may memorise them without learning the wider pattern. A model also needs to be checked on examples it did not train on. Good performance on training examples alone does not prove that it will work well on new ones.

A model can still make mistakes after testing. Its performance may change when real-world inputs differ from the examples it learned from.

3. People and responsibility

People choose the task, decide what data is appropriate, design and train the system, evaluate its results and decide how its outputs are used. A human review is especially important when an output could affect someone's safety, education, money or access to a service.

Worked example: a school message filter (illustrative only)

Suppose a school wants to sort incoming messages into “spam” and “not spam”. People prepare labelled training examples. The model learns patterns from those examples. It then receives a new message and predicts a category. A staff member should be able to review uncertain or important messages, because a genuine school message could be incorrectly flagged.

This is a simplified teaching example, not a real trained model or a claim that one keyword can reliably identify spam.

AI outputs are not guaranteed facts or decisions. Check important results, consider what information may be missing and make sure a responsible person can correct errors.

4. Different machine-learning tasks

  • Classification: predicts a category, such as “spam” or “not spam”.
  • Regression: predicts a number, such as an estimated journey time.
  • Clustering: groups similar examples when the groups are not already labelled for the model.
  • Generative AI: creates content such as text, images, audio or code based on patterns learned during training and the input it receives.

These are not all the same task. A system that sorts items into categories does something different from a system that estimates a number or generates a paragraph.

Quick comparison: “Will this message be spam?” is a classification question. “How many minutes might the trip take?” is a regression question. “Which messages are similar to each other?” could be a clustering task.

Common mistakes to avoid

Assuming every AI system uses machine learning or learns in the same way. AI is a broad field with different approaches.
Thinking a model understands examples exactly as a person does. A model learns patterns for a task; this is not the same as human experience or understanding.
Testing only on the examples used for training. Separate test examples help show whether the model can handle new inputs.
Believing fluent or confident output must be correct. Models can produce incorrect, incomplete or unsuitable results.
Ignoring who selected the data and labels. Missing or mistaken examples can affect the model's results.

Practice exercises

Try answering before opening the suggested responses.

1. Identify input and output

A photo app receives a picture and predicts whether it contains a cat. The input is the picture; the output is the predicted category, such as “cat” or “no cat”.

2. Explain why training examples matter

The model learns patterns from the examples it is given. If important situations are missing or labels are wrong, it may make unreliable predictions on new examples.

3. Why use separate test examples?

To check how the trained model performs on examples it did not learn from. This gives better evidence about how it may handle new inputs than checking training examples alone.

4. Classify the task

A system predicts the number of minutes a bus journey will take. This is regression because the output is a number. A system that predicts “late” or “on time” is classification because the output is a category.

5. What should happen after an important AI prediction?

Check the result against appropriate evidence and involve a responsible person when the decision matters. The model's output should not automatically become the final decision.

Lesson recap

  • AI is a broad field; machine learning is one way to build systems that learn patterns from data.
  • Training examples help adjust a model; new inputs receive outputs or predictions.
  • Separate test examples help evaluate how a model handles unfamiliar inputs.
  • Classification, regression, clustering and generative AI describe different tasks or approaches.
  • People remain responsible for checking and deciding how important outputs are used.
