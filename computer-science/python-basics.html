Python Variables, Input and Output

Programs store and process information. In Python, a variable is a name that refers to a value. Input receives information and output communicates a result. These basics help turn an algorithm into a program.

Learning time: 35–40 minutes · Beginner level · Free study resource

What you will learn

  • Explain what a variable is and choose clear, descriptive names.
  • Recognise the four main data types: int, float, str and bool.
  • Use input() and print() to read from and write to the user.
  • Convert text input to numbers with int() and float() before doing arithmetic.
  • Use arithmetic operators, string operations and f-strings correctly.
  • Read a complete program, predict its output, and fix the most common errors.

1. Variables and values

A variable is a name that refers to a value stored in the computer's memory. When you write age = 12, Python stores the number 12 and lets you use the name age to refer to it later. The value can change: after age = 12, the line age = 13 makes age refer to 13 instead. That is why it is called a variable — it can vary.

Choose names that describe what the value means. score, number_of_books and player_name are good names; x, thing and data2 tell the reader nothing. Python names must start with a letter or an underscore, and may contain letters, digits and underscores — but no spaces. my_score is valid; my score and 2nd_score are not.

Assignment works from right to left: Python works out the value on the right of = first, then stores it under the name on the left. So total = 4 + 3 stores 7 in total, and total = total + 5 takes the old value of total, adds 5, and stores the new result back in total.

Worked example 1 — assignment and updating. 
score = 10
score = score + 5
print(score)
Trace it: after line 1, score is 10. Line 2 reads the old value (10), adds 5 to get 15, and stores 15 in score. Line 3 prints 15. Output: 15. Check: the second line does not create a new variable — it updates the same one.
Worked example 2 — swapping two values. 
a = 3
b = 7
a, b = b, a
print(a, b)
The line a, b = b, a swaps the two values in one step. After it, a is 7 and b is 3. Output: 7 3. Check: without the swap, printing a, b would give 3 7.

2. Common data types

Every value in Python has a type — a kind that decides what you can do with it. The four types beginners meet first are: int (whole numbers such as 7, 0 and -4), float (numbers with a decimal point such as 3.5 and 0.25), str (text such as "Learnora" and "7"), and bool (the two values True and False). Note that "7" in quotes is a string, not a number — the quotes change the type, even though the characters look the same.

You can ask Python for a value's type with the type() function: type(7) gives <class 'int'>, type(3.5) gives <class 'float'>, type("7") gives <class 'str'> and type(True) gives <class 'bool'>. The type matters because the same operator can do different things to different types: 7 + 3 is arithmetic and gives 10, while "7" + "3" joins two strings and gives "73".

Worked example 3 — type decides the result. 
print(7 + 3)
print("7" + "3")
print(3 * "ha")
Line 1 adds two integers: 10. Line 2 joins two strings: "73". Line 3 repeats a string three times: "hahaha". Output: 10, then 73, then hahaha. Check: the same symbol + means "add" for numbers and "join" for strings — the type of the values decides.
Worked example 4 — converting between types. int(3.9) gives 3 — it cuts off the decimal part (it does not round up). float(4) gives 4.0. str(25) gives "25". int("12") gives 12, but int("twelve") fails with a ValueError, because "twelve" is not a number written in digits. Check: conversion only works when the value can actually be read as the new type.

3. Arithmetic and strings

Python's arithmetic operators are + (add), - (subtract), * (multiply), / (divide, always gives a float), // (floor division, the whole-number part of the division) and % (remainder). So 7 / 2 is 3.5, 7 // 2 is 3, and 7 % 2 is 1. Powers use **: 2 ** 3 is 8.

Python follows the usual order of operations: brackets first, then powers, then multiplication and division, then addition and subtraction. 2 + 3 * 4 is 14, not 20, because the multiplication happens first. When in doubt, use brackets: (2 + 3) * 4 is 20 and nobody has to guess.

Strings support joining with + and repeating with *, and you can find a string's length with len(): len("Learnora") is 8. Strings are indexed from 0: in word = "Python", word[0] is "P" and word[1] is "y". Strings cannot be changed in place — word[0] = "J" gives a TypeError — but you can build a new string from parts of the old one.

Worked example 5 — operators in order. 
print(10 - 4 * 2)
print((10 - 4) * 2)
print(17 // 3, 17 % 3)
Line 1: multiplication first, 4 * 2 = 8, then 10 - 8 = 2. Line 2: brackets first, 10 - 4 = 6, then 6 * 2 = 12. Line 3: 17 // 3 = 5 and 17 % 3 = 2, because 17 = 5 × 3 + 2. Output: 2, 12, 5 2. Check: 5 × 3 + 2 = 17, so the quotient and remainder are consistent.

4. Input, conversion and output

input() reads a line of text typed by the user — and it always returns a string, even when the user types digits. If the user types 12, input() returns the string "12", not the number 12. That is the single most common beginner mistake: adding the result of input() to a number without converting it first.

Convert before you calculate: use int() for whole numbers and float() for decimal numbers. The pattern is always the same — read the text, convert it, then use the number:

age_text = input("Your age: ")
age = int(age_text)
next_year = age + 1
print(next_year)

If the user types 12, age_text is "12", age is 12, next_year is 13, and the program prints 13. If the user types "twelve" instead, int("twelve") fails with a ValueError — the program cannot turn a word into a number, and it says so.

Worked example 6 — the conversion mistake. 
number_text = input("Enter a number: ")
print(number_text + 3)
If the user types 5, number_text is the string "5". Then "5" + 3 tries to join a string and an integer, and Python stops with a TypeError: can only concatenate str (not "int") to str. The fix is one line: number = int(number_text) before the addition, giving 5 + 3 = 8. Check: the error message names the two types — str and int — which tells you exactly what went wrong.
Worked example 7 — printing with f-strings. 
name = "Ayesha"
age = 13
print(f"Hello, {name}! Next year you will be {age + 1}.")
An f-string starts with f before the opening quote, and anything in curly brackets {} is worked out and put into the text. Here {name} becomes "Ayesha" and {age + 1} becomes 14. Output: Hello, Ayesha! Next year you will be 14. Check: the expression inside the brackets is ordinary Python — you can put a calculation there, not just a variable name.

Worked example: add two whole numbers

This complete program asks for two whole numbers, converts the typed text into integers, adds them and displays the answer.

first_text = input("First whole number: ")
second_text = input("Second whole number: ")

first_number = int(first_text)
second_number = int(second_text)

total = first_number + second_number
print("Sum:", total)

Try it: If the user enters 4 and then 3, the output is Sum: 7. The conversion matters because input() returns text. This example expects whole-number input; entering words instead of digits causes a conversion error.

Extension: Change int() to float() if the program should accept decimal numbers.

Worked example: average of three numbers

A program that reads three test scores and prints their average:

first = int(input("First score: "))
second = int(input("Second score: "))
third = int(input("Third score: "))
average = (first + second + third) / 3
print("Average:", average)

Try it: If the user enters 10, 20 and 30, then first + second + third = 60, and 60 / 3 = 20.0. Output: Average: 20.0. Note the .0: division with / always gives a float, even when the answer is a whole number. The brackets matter — without them, first + second + third / 3 would divide only the third score by 3.

Worked example: temperature converter

Convert a temperature from Celsius to Fahrenheit. The formula is: Fahrenheit = Celsius × 9 / 5 + 32.

celsius = float(input("Temperature in Celsius: "))
fahrenheit = celsius * 9 / 5 + 32
print(f"{celsius}°C is {fahrenheit}°F")

Try it: If the user enters 20, then 20 × 9 = 180, 180 / 5 = 36, and 36 + 32 = 68. Output: 20.0°C is 68.0°F. Check: water freezes at 0°C, which is 32°F — put 0 into the formula: 0 × 9 / 5 + 32 = 32. Correct. float() is used instead of int() so the user can enter a decimal temperature such as 20.5.

Common mistakes to avoid

Mistake 1: Adding input text to a number without converting it. Wrong: input("Age: ") + 1. Correct: convert first — age = int(input("Age: ")), then age + 1.
Mistake 2: Using variable names with spaces or starting with digits. Wrong: my score = 10 or 2nd_score = 5. Correct: my_score = 10.
Mistake 3: Confusing assignment (=) with equality comparison (==). Wrong: using = to test whether two values are equal. Correct: = stores a value; == tests whether two values are equal and gives True or False.
Mistake 4: Forgetting that / always gives a float. Wrong: expecting 7 / 2 to be 3. Correct: 7 / 2 is 3.5; use 7 // 2 for 3.
Mistake 5: Using a variable before it is assigned. Wrong: print(total) before any line sets total. Correct: Python stops with a NameError — assign the variable first.
Mistake 6: Forgetting quotes around text. Wrong: name = Ayesha. Correct: name = "Ayesha" — without quotes, Python thinks Ayesha is a variable name and reports a NameError.

Lesson summary

  • A variable is a name for a stored value. Choose names that describe the value.
  • The four main types are int, float, str and bool. The type decides what an operator does.
  • input() always returns a string. Convert with int() or float() before doing arithmetic.
  • / always gives a float; // gives the whole-number part and % gives the remainder.
  • print() displays output; f-strings let you put values and calculations inside text.
  • Read error messages: they name the types and the line, which usually points at the fix.
