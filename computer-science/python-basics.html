Python Variables, Input and Output

Programs store and process information. In Python, a variable is a name that refers to a value. Input receives information and output communicates a result. These basics help turn an algorithm into a program.

Learning time: 15–20 minutes · Beginner level · Free study resource

What you will learn

  • Explain what a variable represents.
  • Recognise integers, floats, strings and Booleans.
  • Use input and print in a simple example.
  • Convert text input before arithmetic.

1. Variables and values

A variable gives a value a meaningful name. For example, age = 12 stores an integer under the name age. Use descriptive names such as score or number_of_books.

Python uses = for assignment: it stores a value in a variable. It does not test equality.

2. Common data types

An int is a whole number such as 7. A float can contain a decimal such as 3.5. A str is text such as "Learnora". A bool is True or False.

Adding two numbers performs arithmetic, while joining two strings combines text. The type of a value affects what an operation does.

3. Input, conversion and output

input() reads text typed by a user. Even digits typed at the prompt are returned as a string. Use int() for whole-number calculations or float() for decimal calculations. print() displays results.

Example: age_text = input("Your age: "); age = int(age_text); next_year = age + 1; print(next_year). Convert the input before adding one.

Common mistakes to avoid

Adding input text to a number without converting it.
Using variable names with spaces or starting with digits.
Confusing assignment (=) with equality comparison (==).
