HTML and CSS: How Web Pages Work

A web page uses technologies that work together. HTML describes content and structure. CSS controls presentation such as colour, spacing and layout. A browser reads these files and renders the page.

Learning time: 15–20 minutes · Beginner level · Free study resource

What you will learn

  • Describe the roles of HTML and CSS.
  • Recognise common semantic HTML elements.
  • Explain how stylesheets affect presentation.
  • Use headings, links and image alternatives responsibly.

1. HTML gives content structure

HTML elements describe meaning. A page commonly contains a head for metadata and a body for visible content. Headings, paragraphs, lists and links describe the information.

Semantic elements such as header, nav, main, article and footer help browsers, assistive technologies and developers understand each region.

2. CSS controls presentation

CSS rules select elements and apply declarations. A rule for h1 can change heading colour. Flexbox and Grid arrange content across screen sizes.

Responsive design adapts content to different viewports. Flexible widths and media queries can prevent horizontal scrolling on phones.

3. Accessibility matters

Use headings in a logical order, descriptive link text, labels for form controls and meaningful alternative text for informative images. Do not rely on colour alone to communicate meaning.

A link labelled “Read the Grade 7 algorithms lesson” explains its destination better than “Click here”. Test keyboard navigation and narrow mobile layouts.

Worked example: a small semantic web page

HTML gives the content meaning and structure. CSS changes its appearance. Here is a minimal example using a page header, main content and a footer.

<header>
  <p>My Study Page</p>
</header>

<main>
  <h1>Welcome</h1>
  <p>This page has a clear main heading.</p>
</main>

<footer>
  <p>Created for class practice.</p>
</footer>

Add this CSS in a stylesheet to change spacing and keep the content comfortable on narrow screens:

main {
  max-width: 42rem;
  margin: 0 auto;
  padding: 1rem;
}

@media (max-width: 600px) {
  main {
    padding: 0.75rem;
  }
}

What to notice: main identifies the page's primary content. max-width limits line length on wide screens, while the media query adjusts padding on smaller screens. The viewport meta tag should also be present in the document head.

Common mistakes to avoid

Using elements only for visual appearance instead of meaning.
Creating tiny text or horizontal scrolling on phones.
Leaving informative images without useful alternative text.

Worksheet answer guide

  1. A suitable sketch can contain a header for the site heading, nav for navigation, main for the main lesson, an article for a self-contained item, and footer for closing information. Not every page needs every element.
  2. Example: <h1>My first page</h1> and <p>This is a paragraph.</p>.
  3. Check that the viewport meta tag is present, text remains readable, content fits without horizontal scrolling, links and buttons can be reached by keyboard, and images have suitable alternative text.

Accept other semantically appropriate layouts and CSS declarations. A colour declaration such as color: navy; is a valid example of changing text colour.
