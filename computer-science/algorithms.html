Algorithms and Flowcharts

An algorithm is a precise sequence of steps for solving a problem. It can be written in everyday language, pseudocode or code. A flowchart makes the logic visible so that another person can follow and test it.

Learning time: 15–20 minutes · Beginner level · Free study resource

What you will learn

  • Define an algorithm and explain why order matters.
  • Break a task into small, testable steps.
  • Use sequence, selection and repetition.
  • Read basic flowchart symbols.

1. Design clear steps

Start with a goal, identify the information available, then write steps in an order that another person could follow. Each step should describe one clear action.

To find the larger of two numbers: read A and B; compare them; display A if A is larger, otherwise display B. Test equal values too.

2. Three control structures

Sequence runs instructions in order. Selection chooses a path based on a condition, such as IF a score is at least 50. Repetition runs instructions more than once, such as checking every item in a list.

Pseudocode: SET total TO 0; FOR each score; ADD score TO total; DISPLAY total. The loop repeats the addition for every score.

3. Flowchart symbols

An oval marks Start or End, a rectangle represents a process, a parallelogram represents input or output, and a diamond represents a decision. Arrows show direction.

A library example: Start → enter days late → decision: days late greater than zero? → calculate a fine or display no fine → End. Label the decision branches Yes and No.

Common mistakes to avoid

Vague steps that another person cannot follow.
Forgetting boundary cases such as zero or equal values.
A decision diamond with unlabeled branches.

Practice exercises

1. Write five clear steps for borrowing a library book.

2. Describe an algorithm that checks whether a number is even.

3. Name the flowchart symbol used for a decision.

Knowledge check: five questions

Choose one answer for each question. Feedback explains every answer.

1. What is an algorithm?
2. Which shape represents a decision?
3. What is sequence?
4. Which structure repeats instructions?
5. Why test boundary values?
