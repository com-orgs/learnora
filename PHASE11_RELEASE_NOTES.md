# Phase 11 — International Learning Expansion

Date: 3 November 2026

## Delivered on the release branch
- Curriculum-neutral Grade 6–8 mathematics study plan.
- International maths practice workbook with four independent sets:
  - United States: Common Core Grades 6–8
  - England: Key Stage 3
  - Canada: Ontario Grades 6–8
  - Australia: Australian Curriculum Version 9, Years 7–8
- 24 original questions with worked answer keys, plus print-friendly styling.
- Workbook linked from the curriculum hub and all four regional guides.
- Workbook URL included in the production sitemap.
- Print interaction is in a same-origin external JavaScript file to comply with the site's restrictive Content Security Policy.
